STUDIO CONNECT — PREMIUM WEBSITE CONCEPT

Open index.html in Chrome to preview.

Working demo interactions:
- Responsive mobile navigation
- Gallery filters
- Context-aware enquiry buttons (preselect service)
- FAQ expand/collapse
- Phone click-to-call
- Validated enquiry form that opens a prefilled email draft (no recipient configured)

IMPORTANT BEFORE PRESENTING OR PUBLISHING:
- This is an independent speculative concept, not an official Studio Connect website.
- Replace illustrative Unsplash photography with approved studio photos.
- Verify current offerings, hours, address, schedules, class prices and contact email with owner.
- The enquiry form is NOT connected to a backend. It opens a draft in the visitor's email app and requires the visitor to enter a verified recipient address.
- For real bookings, connect an approved scheduling/payment provider and verify privacy/consent requirements.
- This demo uses external image URLs and Google Fonts, so internet access improves its appearance.
